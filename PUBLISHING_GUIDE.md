# Publishing guide

1. **Review and sanitize** every image in `projects/*/evidence` before uploading publicly. Screenshots were extracted as-is from coursework.
2. Visit https://github.com/new and create a public repository named `linux-security-administration-labs` (do not initialize it with a README).
3. Upload the **contents** of this folder through GitHub's upload files interface, or use Git locally.
4. Set the repository About description to: `Linux security administration labs | Bash scripting, access controls, networking, and automation`.
5. Add your original Bash scripts later, if available. Label any reconstructed code clearly.
6. Pin the repository to your GitHub profile and link it from your portfolio website and LinkedIn.

**Warning:** This package is not fully privacy-cleared. Review all images before publication.
