## How to read this portfolio

The images are extracted from submitted coursework, not generated demonstrations. Narratives are editorial summaries based on the supplied materials. **No original `.sh` files were supplied**, so none are represented as original code. Some assignments contain command errors or incomplete attempts; these are retained as authentic learning evidence.

## Publishing checklist

- Review every screenshot for personal information and secrets before making the repository public.
- Confirm each project description accurately represents the work performed.
- Add original `.sh` scripts when recovered from the Linux VM; do not substitute AI-written examples as originals.
- Consider replacing course-instruction screenshots with tightly cropped terminal-only evidence.
- Never upload `/etc/shadow`, password hashes, real passwords, API keys, or private network information.
